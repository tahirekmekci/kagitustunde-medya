# Kağıt Üstünde — yayın görselleri

Bu depo **herkese açıktır.** Instagram, paylaşılacak görselleri buradaki adreslerden indirir.

- Buraya sadece **yayın anında** ve zaten Instagram'da herkese açılacak görseller/videolar konur.
- Taslaklar, onay bekleyen içerikler, şifre veya anahtar **asla** konmaz.
- Asıl çalışma deposu gizlidir.
